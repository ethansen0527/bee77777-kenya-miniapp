The link must always carry /play: without the short name it opens the older main app, not this MiniApp. Variants per channel: change only the code — https://t.me/Bee77777KenyaBot/play?startapp=kenya_ads_tg for Telegram ads, https://t.me/Bee77777KenyaBot/play?startapp=kenya_ads_fb for Facebook. Code rules: letters, numbers, _ and -, max 512 characters in startapp.

2 · How attribution is read on this page

On open, the page reads the code in this order: Telegram.WebApp.initDataUnsafe.start_param → the tgWebAppStartParam parameter in the URL (query and hash, including inside tgWebAppData). The code is validated (letters, numbers, _, - only; max 512) and, if invalid or missing, it shows “no code”. The “Follow the Bot” button reuses that same code in ?start=<code> when it is 64 characters or shorter; for a longer code the button uses the short code bot, because ?start= accepts at most 64 characters.

Data kept separate per country: this page stores nothing. Kenya's data lives in the Kenya Bot (its own user database) and in the Kenya shared sheet; it is not mixed with Peru, West Africa or Chile, which have their own Bot, sheet and page.
